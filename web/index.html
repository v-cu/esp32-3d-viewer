Studio-lit 3D models on a 1.8″ AMOLED

Firmware for the Waveshare ESP32-S3-Touch-AMOLED-1.8 (V2). It renders cars and any other 3D model in real time; you turn them with a finger or by tilting the board.

Install it from this page, then turn your own .glb or .obj files into models for the board. Nothing is uploaded: the conversion runs in your browser.

Install the firmware Convert a model
Installing needs Web Serial, which only Chrome and Edge on a computer have. You can still convert models here and download them.

  1. Connect the board

    Plug it in with a USB-C data cable. A blank board is ready right away. If the board does not answer, hold BOOT, tap RESET, release BOOT and try again. A board that is asleep wakes up with a press of BOOT.

  2. Choose what to write

    Your own models can be written later from the model studio without reinstalling.
